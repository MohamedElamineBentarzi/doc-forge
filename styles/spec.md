# Style: Specification
Voice: impersonal, present tense, normative. RFC 2119 keywords (MUST, SHOULD,
MAY) in caps, used precisely, never decoratively. One sentence of context may
precede normative text per section; no storytelling. Definitions before use;
forward references forbidden. Numbered requirements where testability
matters. Tables for enumerable structures (fields, codes); prose for
behavior. Examples are normative unless marked informative. No hedging, no
"simply", no marketing adjectives. Terminology: exactly the glossary term,
every time — synonyms are bugs.
