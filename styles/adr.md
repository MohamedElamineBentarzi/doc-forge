# Style: Architecture Decision Record set
One decision per ADR. Fixed skeleton: Context (forces, constraints — facts
only) / Decision (active voice: "We will ...") / Consequences (good AND bad;
a consequences section with no downsides is a finding). Past decisions are
immutable; changes come as new ADRs superseding old ones (link both ways).
Terse: an ADR over ~700 words is hiding two decisions. No implementation
detail beyond what the decision fixes. Status line: proposed | accepted |
superseded-by ADR-nnn.
