# Style: Guide / quickstart
Voice: imperative, second person, one reader one terminal. Every step is an
action with a visible expected result ("Run X. You should see Y."). State
prerequisites completely and up front. One happy path; alternatives go to a
short "variations" note at the end, not inline branches. Code blocks are
copy-paste runnable, no placeholders without an immediately preceding
explanation of what to substitute. Troubleshooting table at the end fed by
real failure modes from sources, not imagined ones. Reading time honest:
if a step takes 10 minutes, say so.
