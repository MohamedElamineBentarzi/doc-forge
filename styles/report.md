# Style: Report / analysis
Voice: analytical, impersonal but readable; findings-first. Open with an
executive summary that states conclusions and their confidence, not the
journey ("We found X; evidence is strong/mixed"). Body: each section = one
question, structured as claim -> evidence -> interpretation -> limits.
Separate observation from inference explicitly; every number carries its
source and conditions. Tables/figures for data, prose for reasoning — never
narrate a table row by row. Uncertainty is stated, quantified where possible,
and never hedged rhetorically ("somewhat", "fairly") — give ranges or name
the unknown. Recommendations, if any, go in their own final section, each
traceable to a finding by reference. No suspense, no methodology dumps before
results (methods go in an appendix unless they ARE the finding).
