# Style: Book / long-form prose
Voice: direct second-person-friendly expert; confident, warm, zero fluff.
Motivation-first: every chapter and section opens with the problem or
question it resolves, grounded in something the reader already saw. Prose is
the default; bullets only for genuinely enumerable items, never for
arguments. Examples before abstractions where possible. Transitions do work:
end sections on the tension the next one resolves. Vary sentence length;
read-aloud test applies. Ban: "delve", "it's worth noting", "in today's
world", symmetric triads, exclamation marks. Define each term once, at first
use, then trust the reader.
